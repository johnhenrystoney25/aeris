# THE MULTIVERSE

Godot 4 vertical-slice prototype for an original open-world multiverse action sandbox.

## Current vertical slice

- Main city prototype made from primitive geometry
- Third-person and first-person cameras
- Walk, sprint, jump and basic flight
- Teleport ability
- Size states: tiny, small, normal, large, giant
- Melee attack, block and dodge
- Basic enemy with health/damage
- Physical city -> micro reality portal
- Micro reality -> city return portal
- Data-driven `RealityData` resources

## Controls

- WASD / Arrow keys: move
- Shift: sprint
- Space: jump / ascend while flying
- V: first/third person
- Left mouse: attack
- Right mouse: block
- Q: dodge
- F: toggle flight
- T: teleport
- Z / X: shrink / grow
- E: reserved portal interaction

## Development rule

Functionality comes before final art. Primitive geometry is intentional at this stage. The architecture is designed to grow into reusable abilities, realities, combat, NPC simulation, vehicles and multiplayer without prematurely implementing the complete game.

## Current limitation

The repository has been authored through the connected GitHub integration. It has not been executed in a local Godot runtime from this session, so runtime success is not being claimed until the project is opened/run in Godot.
